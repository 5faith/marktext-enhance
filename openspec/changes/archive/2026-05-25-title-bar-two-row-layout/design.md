## Context

当前标题栏采用单行布局（32px高度），水平菜单、标题和字数统计在同一行，导致元素重叠。用户希望将布局改为两行，并为字数统计弹窗增加透明度。

**当前布局：**
```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [File Edit Paragraph Format Window Theme View Help]  Title  [W 123] [_][□][X] │
└─────────────────────────────────────────────────────────────────────────────┘
```

**目标布局：**
```
┌─────────────────────────────────────────────────────────────────────────────┐
│ File  Edit  Paragraph  Format  Window  Theme  View  Help          [_][□][X] │
├─────────────────────────────────────────────────────────────────────────────┤
│ W 123  │                      Title                                         │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Goals / Non-Goals

**Goals:**
- 将标题栏改为两行布局，分离菜单和标题/字数统计
- 字数统计放在第二行左侧
- 标题居中显示在第二行
- 字数统计弹窗增加透明度（使用 rgba 格式）

**Non-Goals:**
- 不改变菜单项的功能
- 不改变窗口控制按钮的行为
- 不改变其他组件的布局

## Decisions

### 1. 标题栏高度
**决定**：将 `--titleBarHeight` 从 `32px` 改为 `64px`

**理由**：
- 两行各 32px，保持视觉一致性
- 使用 CSS 变量，便于主题切换和维护

**替代方案**：
- 使用固定像素值：不推荐，不利于主题适配
- 动态计算高度：增加复杂度，不必要

### 2. 布局结构
**决定**：使用两层 flexbox 布局

**理由**：
- 第一行：`justify-content: space-between`，菜单在左，窗口按钮在右
- 第二行：`position: relative`，字数统计绝对定位在左侧，标题居中

**替代方案**：
- 使用 CSS Grid：增加复杂度，flexbox 已足够
- 使用绝对定位全部元素：不利于响应式

### 3. 弹窗透明度
**决定**：使用 `rgba(63, 63, 63, 0.9)` 格式，90% 不透明度

**理由**：
- 符合 DESIGN.md 的透明规范
- 保持弹窗内容可读性
- 使用 CSS 变量 `--floatBgColor` 作为基础色

**替代方案**：
- 使用 `opacity` 属性：会影响子元素，不推荐
- 使用 80% 不透明度：可能过于透明，影响可读性

## Risks / Trade-offs

**[风险] 标题栏高度增加可能影响其他组件**
- 缓解：检查所有使用 `--titleBarHeight` 的地方，确保兼容性

**[风险] 弹窗透明度可能影响可读性**
- 缓解：使用 90% 不透明度，保持内容清晰

**[权衡] 两行布局占用更多垂直空间**
- 接受：这是为了消除元素重叠的必要权衡
