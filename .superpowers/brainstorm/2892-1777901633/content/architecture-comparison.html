MarkText 升级方案对比

当前架构 vs 目标架构

当前架构 (Vue2 + Webpack)
Electron Main Process
Renderer Process
Vue 2.6
Vuex 3.x
Vue Router 3.x
Element UI 2.x
Build System
Webpack 5
.electron-vue/
Babel 7
vue-loader 15
问题: 构建慢、热更新慢、Vue2 停止维护、Options API 代码组织困难
目标架构 (Vue3 + Vite)
Electron Main Process
Renderer Process
Vue 3.4+
Pinia (或 Vuex 4)
Vue Router 4.x
Element Plus / Naive UI
Build System
Vite 5+
vite-plugin-electron
原生 ESM
@vitejs/plugin-vue
优势: 极速热更新、Composition API、更好的 TypeScript 支持、更小的打包体积

关键变化

1

Vue 2 → Vue 3

Options API → Composition API，47个 .vue 组件需要迁移

2

Webpack → Vite

移除 .electron-vue/ 配置，改用 vite.config.js + vite-plugin-electron

3

Element UI → Element Plus

UI 组件库升级，API 有 breaking changes

4

Vuex 3 → Pinia/Vuex 4

状态管理升级，Pinia 是 Vue3 推荐方案
